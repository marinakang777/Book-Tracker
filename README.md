## Описание программы

Book Tracker - это графическое приложение для управления списком прочитанных книг. Программа позволяет:
- Добавлять книги с указанием названия, автора, жанра и количества страниц
- Просматривать список всех книг в удобной таблице
- Фильтровать книги по жанру и по количеству страниц (больше указанного числа)
- Удалять книги из списка
- Сохранять данные в JSON-файл и автоматически загружать их при запуске

Приложение проверяет корректность ввода данных и выдает понятные сообщения об ошибках.

## Требования

- Python 3.6 или выше
- Стандартные библиотеки Python (tkinter, json, os) - не требуют дополнительной установки

3. Запустите программу командой:

python book_tracker.py

Примеры использования
Пример 1: Добавление книги
Введите:

Название: "Война и мир"

Автор: "Лев Толстой"

Жанр: "Роман"

Страницы: "1225"

Нажмите "Добавить книгу"

Книга появится в таблице

Пример 2: Фильтрация книг
Чтобы показать только книги жанра "Фантастика", введите "фантастика" в поле фильтра по жанру и нажмите "Применить фильтр"

Чтобы показать книги длиннее 300 страниц, введите "300" в поле фильтра по страницам

Можно использовать оба фильтра одновременно

Пример 3: Удаление книги
Кликните на книгу в таблице (строка выделится)

Нажмите "Удалить выбранную книгу"

Книга будет удалена из списка и из файла

Тестовые сценарии
Тест 1: Проверка валидации ввода
Попробуйте добавить книгу с пустым полем → получите сообщение об ошибке

Попробуйте ввести буквы в поле "Страницы" → получите сообщение об ошибке

Попробуйте ввести 0 или отрицательное число → получите сообщение об ошибке

Тест 2: Проверка сохранения данных
Добавьте несколько книг

Закройте программу

Откройте программу снова → книги должны отображаться

Тест 3: Проверка фильтрации
Добавьте книги разных жанров и с разным количеством страниц

Примените фильтр по жанру "фантастика" → должны отобразиться только книги этого жанра

Добавьте фильтр по страницам "200" → должны отобразиться только фантастические книги с более чем 200 страницами

Нажмите "Сбросить фильтр" → должны отобразиться все книги

Формат данных
Данные сохраняются в файле books.json в формате:

json
[
  {
    "title": "Название книги",
    "author": "Автор",
    "genre": "Жанр",
    "pages": 300
  }
]
Возможные проблемы и решения
Проблема: При запуске ошибка "No module named tkinter"
Решение: Установите tkinter:

Ubuntu/Debian: sudo apt-get install python3-tk

Проблема: Не сохраняются данные
Решение: Убедитесь, что у программы есть права на запись в папке
